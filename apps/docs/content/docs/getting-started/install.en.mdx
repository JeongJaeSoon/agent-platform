Getting started assumes you already have a Werft server. If you do not, bring one up first in [Run a server](/run-server/dev-server).

## What you need

| Item | Description |
| --- | --- |
| Server address | The URL of the Werft API. For a development server it is `http://127.0.0.1:3000` |
| API key | A key with the `sessions:read`, `sessions:write`, `sessions:approve`, and `sessions:control` scopes. On a development server, create one as in [Get an API key](/run-server/dev-server#get-an-api-key) |
| curl, jq, uuidgen | Used for the HTTP calls and JSON handling in the examples |

Keep the server address in `API` and the key in `KEY`, and go on to the next page in the same terminal. Key scopes and how to issue keys are described in [API key](/api-keys).
