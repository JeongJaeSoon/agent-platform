시작하기는 Werft 서버가 이미 있다고 전제한다. 서버가 없으면 [서버 실행하기](/run-server/dev-server)에서 먼저 띄운다.

## 필요한 것

| 항목 | 설명 |
| --- | --- |
| 서버 주소 | Werft API의 URL. 개발용 서버는 `http://127.0.0.1:3000`이다 |
| API key | `sessions:read`, `sessions:write`, `sessions:approve`, `sessions:control` scope가 있는 key. 개발용 서버에서는 [API key 받기](/run-server/dev-server#api-key-받기)로 만든다 |
| curl, jq, uuidgen | 예제의 HTTP 호출과 JSON 처리에 쓴다 |

서버 주소는 `API`, key는 `KEY` 변수에 두고 같은 터미널에서 다음 페이지로 넘어간다. key의 scope와 발급 방법은 [API key](/api-keys)에 있다.
