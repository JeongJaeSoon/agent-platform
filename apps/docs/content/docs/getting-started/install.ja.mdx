はじめには、Werft サーバーがすでにあることを前提にする。サーバーがなければ、先に[サーバーを動かす](/run-server/dev-server)で立ち上げる。

## 必要なもの

| 項目 | 説明 |
| --- | --- |
| サーバーのアドレス | Werft API の URL。開発用サーバーなら `http://127.0.0.1:3000` である |
| API キー | `sessions:read`、`sessions:write`、`sessions:approve`、`sessions:control` の scope を持つキー。開発用サーバーでは [API キーを取得する](/run-server/dev-server#api-キーを取得する)で作成する |
| curl, jq, uuidgen | 例の HTTP 呼び出しと JSON の処理に使う |

サーバーのアドレスは `API`、キーは `KEY` 変数に入れ、同じターミナルで次のページに進む。キーの scope と発行方法は [API キー](/api-keys) にある。
