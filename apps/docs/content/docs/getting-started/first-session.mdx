세션 하나를 처음부터 끝까지 돈다. 에이전트가 파일을 쓰려다 권한을 묻고, 스크립트가 허락하고, 다음 메시지가 같은 작업 트리에서 이어지고, 마지막에 세션을 닫는다. [SDK 설치](/getting-started/install)의 `werft` 클라이언트를 쓴다. key에 `sessions:approve`와 `sessions:control`도 있어야 한다.

## 파일을 쓰는 세션 만들기

이 대본은 Bash로 `hello.txt`를 쓴다. `claude-coding-local` 프로필은 파일을 바꾸는 명령 전에 권한을 묻는다.

<Tabs groupId="client" persist items={["SDK", "HTTP API"]}>
<Tab>

```ts title="approve-and-close.ts"
import {
  closeResult,
  type PendingRequestHandlers,
  waitForReceipt,
  waitForTurn,
} from "@werft-ai/sdk";
import { werft } from "./werft.ts";

const signal = AbortSignal.timeout(5 * 60_000);
const COMMAND = "echo alpha > hello.txt";

const created = await werft.sessions.create({
  profile_id: "claude-coding-local",
  repository_id: "sample-app",
  message: `GATE-SPEC ${JSON.stringify({
    id: "first",
    steps: [
      {
        tool: "Bash",
        input: { command: COMMAND, description: "write hello.txt" },
      },
    ],
    final: "wrote hello.txt",
  })}`,
});
const sessionId = created.session_id;
```

</Tab>
<Tab>

```bash
created=$(curl -sS "$API/v1/sessions" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg m 'GATE-SPEC {"id":"first","steps":[{"tool":"Bash","input":{"command":"echo alpha > hello.txt","description":"write hello.txt"}}],"final":"wrote hello.txt"}' \
    '{profile_id: "claude-coding-local", repository_id: "sample-app", message: $m}')")
SID=$(echo "$created" | jq -r .session_id)
echo "$SID"
```

본문을 `jq -nc --arg`로 만들면 메시지 안의 따옴표를 손으로 escape하지 않아도 된다.

</Tab>
</Tabs>

## 권한 요청에 답하기

세션이 권한을 묻고 멈추면 `status`가 `needs_input`이 된다. SDK에서는 `waitForTurn`에 handler를 넘긴다. turn을 기다리는 동안 생긴 권한 요청과 질문이 handler로 온다.

<Tabs groupId="client" persist items={["SDK", "HTTP API"]}>
<Tab>

```ts title="approve-and-close.ts (이어서)"
// Allow the exact command this script expects, deny everything else.
const approvals: PendingRequestHandlers = {
  permission(request) {
    console.log("asked:", request.tool, request.input);
    const command = (request.input as { command?: unknown } | null)?.command;
    if (request.tool === "Bash" && command === COMMAND)
      return { decision: "allow" };
    return { decision: "deny", reason: `This script only allows: ${COMMAND}` };
  },
};

const first = await waitForTurn(werft, sessionId, created.turn_id, {
  signal,
  onRequest: approvals,
  onAnswer: (outcome) => console.log(`answered: ${outcome.outcome}`),
});
console.log(`turn ${first.turn_id}: ${first.status}`);
```

```text
asked: Bash { command: 'echo alpha > hello.txt', description: 'write hello.txt' }
answered: accepted
turn 1: completed
```

handler가 `undefined`를 돌려주거나 그 종류의 handler가 없으면 요청을 열어 두고 사람에게 맡긴다.

</Tab>
<Tab>

```bash
until [ "$(curl -sS "$API/v1/sessions/$SID" -H "Authorization: Bearer $KEY" | jq -r .status)" = needs_input ]; do
  sleep 2
done
curl -sS "$API/v1/sessions/$SID/pending-requests" -H "Authorization: Bearer $KEY" \
  | jq '.items[] | {request_id, kind, tool, command: .input.command}'
```

```text
{
  "request_id": "req_…",
  "kind": "permission",
  "tool": "Bash",
  "command": "echo alpha > hello.txt"
}
```

```bash
REQ=$(curl -sS "$API/v1/sessions/$SID/pending-requests" -H "Authorization: Bearer $KEY" | jq -r '.items[0].request_id')
curl -sS "$API/v1/sessions/$SID/answers" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg r "$REQ" '{request_id: $r, kind: "permission", decision: "allow"}')" \
  | jq '{receipt_status, approval: .approval.surface}'
until [ "$(curl -sS "$API/v1/sessions/$SID/turns/1" -H "Authorization: Bearer $KEY" | jq -r .status)" = completed ]; do
  sleep 2
done
```

```text
{
  "receipt_status": "accepted",
  "approval": "api"
}
```

레퍼런스: [`GET /v1/sessions/{id}/pending-requests`](/reference/http-api/pending-requests/listPendingRequests), [`POST /v1/sessions/{id}/answers`](/reference/http-api/pending-requests/answerPendingRequest)

</Tab>
</Tabs>

거절은 `decision: "deny"`와 `reason`이다. 답하지 않은 요청은 30분 뒤 거절로 끝난다. 자세한 내용은 [승인 대기와 재개](/sessions/waiting-and-resume)에 있다.

## 이어서 보내기

같은 세션에 메시지를 보내면 다음 turn이 된다. worker는 같은 작업 트리와 같은 Claude Code 대화를 이어 쓴다. 읽기 명령은 권한을 묻지 않는다.

<Tabs groupId="client" persist items={["SDK", "HTTP API"]}>
<Tab>

```ts title="approve-and-close.ts (이어서)"
const sent = await werft.sessions.messages.send(sessionId, {
  message:
    'GATE-SPEC {"id":"second","steps":[{"tool":"Bash","input":{"command":"cat hello.txt","description":"read hello.txt"}}],"final":"read it"}',
});
const second = await waitForTurn(werft, sessionId, sent.turn_id, { signal });
console.log(`turn ${second.turn_id}: ${second.status}`);
```

```text
turn 2: completed
```

</Tab>
<Tab>

```bash
curl -sS "$API/v1/sessions/$SID/messages" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg m 'GATE-SPEC {"id":"second","steps":[{"tool":"Bash","input":{"command":"cat hello.txt","description":"read hello.txt"}}],"final":"read it"}' '{message: $m}')" \
  | jq '{turn_id, receipt_status}'
until [ "$(curl -sS "$API/v1/sessions/$SID/turns/2" -H "Authorization: Bearer $KEY" | jq -r .status)" = completed ]; do
  sleep 2
done
curl -sS "$API/v1/sessions/$SID/turns" -H "Authorization: Bearer $KEY" | jq -c '.items[] | {turn_id, status}'
```

```text
{
  "turn_id": "2",
  "receipt_status": "accepted"
}
{"turn_id":"1","status":"completed"}
{"turn_id":"2","status":"completed"}
```

레퍼런스: [`POST /v1/sessions/{id}/messages`](/reference/http-api/messages-and-turns/appendSessionMessage)

</Tab>
</Tabs>

## 닫기

할 일을 마친 세션은 닫는다. 진행 중인 turn을 끝까지 돌리고 checkpoint를 남긴 뒤 `closed`가 된다. 제어 요청에는 지금 세션의 `revision`을 `expected_revision`으로 넘긴다. SDK는 이 값을 대신 읽어 채우지 않는다.

<Tabs groupId="client" persist items={["SDK", "HTTP API"]}>
<Tab>

```ts title="approve-and-close.ts (이어서)"
const { revision } = await werft.sessions.get(sessionId);
const accepted = await werft.sessions.close(sessionId, {
  expected_revision: revision,
  reason: "first session done",
});
const receipt = await waitForReceipt(werft, accepted.receipt_id, { signal });
console.log(`close: ${receipt.status}`, closeResult(receipt));

const session = await werft.sessions.get(sessionId);
console.log(session.status, session.admission_state);
```

```text
close: succeeded {
  checkpoint_revision: 1,
  cancelled_turn_count: 0,
  resulting_admission_state: 'closed'
}
stopped closed
```

</Tab>
<Tab>

```bash
REV=$(curl -sS "$API/v1/sessions/$SID" -H "Authorization: Bearer $KEY" | jq .revision)
curl -sS "$API/v1/sessions/$SID/close" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --argjson r "$REV" '{expected_revision: $r, reason: "first session done"}')" \
  | jq '{receipt_status}'
until [ "$(curl -sS "$API/v1/sessions/$SID" -H "Authorization: Bearer $KEY" | jq -r .admission_state)" = closed ]; do
  sleep 2
done
curl -sS "$API/v1/sessions/$SID" -H "Authorization: Bearer $KEY" | jq '{status, admission_state}'
```

```text
{
  "receipt_status": "accepted"
}
{
  "status": "stopped",
  "admission_state": "closed"
}
```

레퍼런스: [`POST /v1/sessions/{id}/close`](/reference/http-api/session-control/closeSession)

</Tab>
</Tabs>

닫힌 세션에는 메시지를 더 보낼 수 없다(409 `SESSION_CLOSED`).
