---
title: "첫 세션"
description: 권한 요청에 답하고, 메시지를 이어 보내고, 세션을 닫는다
---

세션 하나를 처음부터 끝까지 돈다. 에이전트가 파일을 쓰려다 권한을 묻고, 사람이 허락하고, 다음 메시지가 같은 작업 트리에서 이어지고, 마지막에 세션을 닫는다. [Quickstart](/getting-started/quickstart)에서 만든 `API`와 `KEY`를 같은 터미널에서 쓴다.

## 파일을 쓰는 세션 만들기

이 대본은 Bash로 `hello.txt`를 쓴다. 로컬 프로필은 파일을 바꾸는 명령 전에 권한을 묻는다.

```bash
created=$(curl -sS "$API/v1/sessions" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg m 'GATE-SPEC {"id":"first","steps":[{"tool":"Bash","input":{"command":"echo alpha > hello.txt","description":"write hello.txt"}}],"final":"wrote hello.txt"}' \
    '{profile_id: "claude-coding-local", repository_id: "sample-app", message: $m}')")
SID=$(echo "$created" | jq -r .session_id)
echo "$SID"
```

본문을 `jq -nc --arg`로 만들면 메시지 안의 따옴표를 손으로 escape하지 않아도 된다.

## 권한 요청 기다리기

세션이 권한을 묻고 멈추면 `status`가 `needs_input`이 된다.

```bash
until [ "$(curl -sS "$API/v1/sessions/$SID" -H "Authorization: Bearer $KEY" | jq -r .status)" = needs_input ]; do
  sleep 2
done
curl -sS "$API/v1/sessions/$SID/pending-requests" -H "Authorization: Bearer $KEY" \
  | jq '.items[] | {request_id, kind, tool, command: .input.command}'
```

```text
{
  "request_id": "req_…",
  "kind": "permission",
  "tool": "Bash",
  "command": "echo alpha > hello.txt"
}
```

## 허락하기

```bash
REQ=$(curl -sS "$API/v1/sessions/$SID/pending-requests" -H "Authorization: Bearer $KEY" | jq -r '.items[0].request_id')
curl -sS "$API/v1/sessions/$SID/answers" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg r "$REQ" '{request_id: $r, kind: "permission", decision: "allow"}')" \
  | jq '{receipt_status, approval: .approval.surface}'
until [ "$(curl -sS "$API/v1/sessions/$SID/turns/1" -H "Authorization: Bearer $KEY" | jq -r .status)" = completed ]; do
  sleep 2
done
```

```text
{
  "receipt_status": "accepted",
  "approval": "api"
}
```

거절하려면 `"decision": "deny"`와 `"reason"`을 보낸다. 답하지 않은 요청은 30분 뒤 거절로 끝난다. 자세한 내용은 [승인 대기와 재개](/sessions/waiting-and-resume)에 있다.

## 이어서 보내기

같은 세션에 메시지를 보내면 다음 turn이 된다. worker는 같은 작업 트리와 같은 Claude Code 대화를 이어 쓴다. 읽기 명령은 권한을 묻지 않는다.

```bash
curl -sS "$API/v1/sessions/$SID/messages" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg m 'GATE-SPEC {"id":"second","steps":[{"tool":"Bash","input":{"command":"cat hello.txt","description":"read hello.txt"}}],"final":"read it"}' '{message: $m}')" \
  | jq '{turn_id, receipt_status}'
until [ "$(curl -sS "$API/v1/sessions/$SID/turns/2" -H "Authorization: Bearer $KEY" | jq -r .status)" = completed ]; do
  sleep 2
done
curl -sS "$API/v1/sessions/$SID/turns" -H "Authorization: Bearer $KEY" | jq -c '.items[] | {turn_id, status}'
```

```text
{
  "turn_id": "2",
  "receipt_status": "accepted"
}
{"turn_id":"1","status":"completed"}
{"turn_id":"2","status":"completed"}
```

## 닫기

할 일을 마친 세션은 닫는다. 진행 중인 turn을 끝까지 돌리고 checkpoint를 남긴 뒤 `closed`가 된다. 제어 요청에는 지금 세션의 `revision`을 `expected_revision`으로 보낸다.

```bash
REV=$(curl -sS "$API/v1/sessions/$SID" -H "Authorization: Bearer $KEY" | jq .revision)
curl -sS "$API/v1/sessions/$SID/close" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --argjson r "$REV" '{expected_revision: $r, reason: "first session done"}')" \
  | jq '{receipt_status}'
until [ "$(curl -sS "$API/v1/sessions/$SID" -H "Authorization: Bearer $KEY" | jq -r .admission_state)" = closed ]; do
  sleep 2
done
curl -sS "$API/v1/sessions/$SID" -H "Authorization: Bearer $KEY" | jq '{status, admission_state}'
```

```text
{
  "receipt_status": "accepted"
}
{
  "status": "stopped",
  "admission_state": "closed"
}
```

닫힌 세션에는 메시지를 더 보낼 수 없다(409 `SESSION_CLOSED`).
