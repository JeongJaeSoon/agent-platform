カードは、エージェントが何者で何をすべきかを記した定義である。カードを修正すると新しいバージョンが作成され、以前のバージョンは変更されない。

## カードのフィールド

| フィールド | 必須 | 内容 |
| --- | --- | --- |
| `role` | はい | 1 行のロール。200 文字まで |
| `instructions` | はい | 指示文。20,000 文字まで |
| `model` | はい | モデル名。リリースを作成するとき、実行プロファイルで実行できるモデルのひとつでなければならない |
| `capabilities.tools` | はい | 使うツール名の一覧。実行プロファイルにあるツールでなければならない。`null` ならリリース作成時のプロファイルのツールすべて |
| `capabilities.mcp` | はい | 現在は `null` のみ受け付ける |
| `capabilities.forbidden` | | 禁止するツール名。Web コンソールは新しいカードに `[]` を入れ、既存の値は表示して消すことだけができる |
| `capabilities.tool_policy` | | ツールごとの `allow`・`ask`・`deny` |
| `capabilities.credential_refs` | | 使う認証情報の名前 (値ではない)。[権限](/agents/permissions) |
| `language` | | `ko` (デフォルト) または `en` |
| `rules` | | `{id, text, source}` の一覧。`source` は `user` または `correction` |

## Web コンソールでツールを選ぶ

カードの編集 (新しいエージェントの「役割」ステップ、エージェント詳細のカード編集) の「使用できるツール」は、プロファイル 1 つのツールのチェックリストである。

- 「ツールを表示するプロファイル」: カードのモデルを実行するプロファイルからひとつ選ぶ。新しいエージェントの流れでは、リポジトリなしでリリースできるプロファイルを先に並べ、選んだプロファイルをリリースのステップで先に選んでおく。この値はカードに保存しない。
- 「リリース時にプロファイルで許可されたすべてのツール」がオンなら `tools: null` である。オフにすると、チェックしたツールが `tools` になる。チェックを外すことが禁止である。
- 保存するとき、チェックを外した組み込みツールの `tool_policy.per_tool` の項目を消す。リリースは実行しない組み込みツールのポリシーを拒否するためである。MCP ツールのポリシーは残る。
- `tools` にプロファイルにない名前があれば「プロファイルにないツール」としてチェックされたまま表示され、オフにすることだけができる。
- 一覧の下に、選んだツールをすべて許可するプロファイルの数が出る。0 なら保存できない。
- 既存のカードに `forbidden` があれば一覧で表示され、「禁止ツールを消す」で空にできる。

## 現在モデルが読むもの

<Callout type="warn">
カードの `role`・`instructions`・`rules` はバージョンとリリースに保存されセッションに固定されるが、まだモデルには渡されない。
</Callout>

現在 worker がモデルに追加する指示は 2 つである。

- リポジトリルートの `CLAUDE.md`。実行プロファイルが `project_settings.claude_md: true` のとき、コミットされた内容を読む。ローカルプロファイル `claude-coding-local` では有効になっている。
- リポジトリのないセッションでは、人に渡すファイルを `out/` に置くよう指示する 1 行。

そのため、エージェントに仕事の進め方を伝えるには、現在はリポジトリの `CLAUDE.md` に書く。

## 修正とバージョン

カードを修正すると、`PATCH /v1/agents/{id}` が新しいバージョンを追加する。名前だけを変えるときは `name` だけを送る。すでにあるバージョンと同じカードを送った場合は何も追加されない。[作成](/agents/create)の `AID` と `WEB` を引き続き使う。

```bash
curl -sS -X PATCH "$API/v1/agents/$AID" "${WEB[@]}" -d '{
  "card": {
    "role": "저장소를 읽고 질문에 답한다",
    "instructions": "Answer briefly. Cite file paths. Say when you are unsure.",
    "model": "claude-sonnet-5",
    "language": "en",
    "capabilities": { "tools": ["Read", "Grep", "Glob"], "mcp": null },
    "rules": [{ "id": "no-guess", "text": "Never invent a file path.", "source": "user" }]
  }
}' | jq -c '.versions[] | {version_no, language: .card.language}'
```

```text
{"version_no":1,"language":"ko"}
{"version_no":2,"language":"en"}
```

新しいバージョンは有効なリリースを変更しない。使うには、そのバージョンでリリースを作成して有効化する ([作成](/agents/create#リリースの作成))。Web コンソールでは、エージェント詳細の「保存」が同じ処理を行い、2 つのバージョンの差分を表示する。
