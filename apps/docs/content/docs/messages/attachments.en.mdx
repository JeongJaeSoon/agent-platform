<Callout type="warn">
Attaching files to a message is not available yet. A message body is a single UTF-8 text string of up to 32,768 bytes.
</Callout>

The only required field of `POST /v1/sessions/{id}/messages` is the text `message`. There is no field to carry a file. If the length is exceeded, the response is 413.

```bash
LONG=$(head -c 32769 /dev/zero | tr '\0' a)
curl -sS -o /dev/null -w '%{http_code}\n' "$API/v1/sessions/$SID/messages" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --arg m "$LONG" '{message: $m}')"
```

```text
413
```

Commit the files the agent needs to read to the repository the session uses, and point to them by path in the message. The session clones that repository when it starts.
