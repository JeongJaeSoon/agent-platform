---
title: "SDKサンプルの実行設定"
description: SDKサンプルCLIが読む任意の環境変数
---

次の値はサーバー設定ではなく、`examples/sdk-approver/src/session-close.ts` CLIの任意設定です。準備と実行の手順は[サンプルのREADME](https://github.com/JeongJaeSoon/werft/blob/main/examples/sdk-approver/README.md)にあります。

| 環境変数 | 動作 |
| --- | --- |
| `WERFT_AGENT_RELEASE_ID` | エージェントキーで実行するリリースID。設定するとセッション作成に`agent_release_id`を送り、profileとrepositoryの設定は使いません。省略すると、既存のユーザーキー例のprofileとrepositoryの経路を使います。 |
| `WERFT_APPROVER_API_KEY` | セッションを読み、承認する別のユーザーキー。`sessions:read`、`sessions:approve`、セッションへのアクセス権限が必要です。省略すると既定のSDKクライアントで答えます。セッションを開始したキーはそのセッションを承認できないため、エージェントの経路では別の承認者(別のキーまたは人)が必要です。 |

サンプルはFAKEモデル専用です。APIキーはソースやログに書かず、実行環境から渡します。
