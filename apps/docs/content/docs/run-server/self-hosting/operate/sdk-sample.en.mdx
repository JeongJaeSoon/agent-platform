---
title: "SDK sample settings"
description: Optional environment variables the SDK sample CLI reads
---

These values are optional settings for the `examples/sdk-approver/src/session-close.ts` CLI, not server settings. Setup and how to run the sample are in the [sample README](https://github.com/JeongJaeSoon/werft/blob/main/examples/sdk-approver/README.md).

| Environment variable | Effect |
| --- | --- |
| `WERFT_AGENT_RELEASE_ID` | The release ID to run with an agent key. When set, session creation sends `agent_release_id` and the profile and repository settings are not used. When unset, the sample follows the profile and repository path of the existing user-key example. |
| `WERFT_APPROVER_API_KEY` | A separate user key that reads and approves the session. It needs `sessions:read`, `sessions:approve` and access to the session. When unset, the sample answers with the default SDK client. The key that started a session cannot approve it, so the agent path needs a separate approver (another key or a person). |

The sample works with the FAKE model only. Pass the API key through the environment; do not put it in source or logs.
