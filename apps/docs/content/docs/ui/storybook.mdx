개별 컴포넌트의 API(props)와 상태별 모습은 Storybook에 있다. 이 문서 사이트와 같은 곳에 올라가 있다.

- <SiblingLink href="/storybook/">Storybook 열기</SiblingLink>

## 들어 있는 것

| 그룹 | 컴포넌트 |
| --- | --- |
| Primitives | `Badge`, `Button`, `Card`, `Checkbox`, `Dialog`, `Field`, `Input`, `NativeSelect`, `RadioGroup`, `Stepper`, `Tabs`, `Textarea` |
| States | `EmptyState`, `ErrorState`, `Skeleton` |
| Patterns | `ConfirmDialog`, `DestructiveActionDialog`, `Receipt`, `StatusLabel`, 세션 조각(`ApprovalCard`, `Composer`, `Message`, `QuestionCard`, `SessionRow`, `SessionStatusLabel`, `StageIndicator`, `Timeline`) |
| Blocks | `Blocks/Session`: `SessionList`, `SessionDetail`, `ApprovalInbox`의 빈 목록, 실패, 읽기 전용, 모바일 상태 |
| Screens | `Sessions panel` |

블록 story는 가짜 API 응답으로 그린다. 서버 없이 상태를 바꿔 볼 수 있다. toolbar에서 언어(`ko`, `ja`, `en`)와 테마(밝게, 어둡게)를 바꾼다.

## 로컬에서 띄우기

컴포넌트를 고치면서 보려면 저장소 루트에서 띄운다.

```sh
bun run --cwd apps/storybook dev
```

`http://127.0.0.1:6006`에서 열린다.
