Werft 웹 콘솔의 화면은 두 패키지로 만든다. 같은 패키지로 다른 React 앱에 세션 목록과 세션 화면을 넣을 수 있다.

| 패키지 | 들어 있는 것 |
| --- | --- |
| `@werft-ai/ui` | 디자인 토큰(`tokens.css`), Tailwind 연결(`theme.css`), primitive(`Button`, `Card`, `Dialog`, `Tabs` 등), 상태 표시(`StatusLabel`, `ErrorState`, `Skeleton`, `EmptyState`), 세션 조각(`Timeline`, `Composer`, `ApprovalCard`, `QuestionCard`) |
| `@werft-ai/react` | 서버 상태를 읽고 쓰는 hook(`useSessions`, `useSession`, `useSessionEvents`, `useSendMessage`, `useAnswer` 등)과 `AgentPlatformProvider`. `@werft-ai/react/blocks`에는 데이터까지 읽어 그리는 세션 블록 `SessionList`, `RecentSessions`, `WaitingSessions`, `SessionDetail`, `ApprovalInbox`가 있다 |

`@werft-ai/ui`는 받은 상태를 그리기만 한다. API를 부르거나 권한을 판단하지 않는다. API 호출은 `@werft-ai/react`의 hook과 블록이 맡는다.

<Callout type="warn">
두 패키지는 npm에 올라가 있지 않다(`private`, 버전 0.0.0). 외부 저장소의 앱에 설치해 쓰는 방법은 아직 제공하지 않는다. 지금은 이 저장소 안의 앱에서만 workspace 패키지로 가져올 수 있다. 패키지는 빌드된 JavaScript가 아니라 TypeScript 소스를 내보내므로, Vite처럼 TypeScript를 컴파일하는 번들러가 필요하다.
</Callout>
