個別コンポーネントの API(props)と状態別の見た目は Storybook にある。このドキュメントサイトと同じ場所に公開されている。

- <SiblingLink href="/storybook/">Storybook を開く</SiblingLink>

## 含まれているもの

| グループ | コンポーネント |
| --- | --- |
| Primitives | `Badge`, `Button`, `Card`, `Checkbox`, `Dialog`, `Field`, `Input`, `NativeSelect`, `Popover`, `RadioGroup`, `Stepper`, `Tabs`, `Textarea` |
| States | `EmptyState`, `ErrorState`, `Skeleton` |
| Patterns | `ConfirmDialog`, `DestructiveActionDialog`, `Receipt`, `StatusLabel`, セッションの部品(`ApprovalCard`, `Composer`, `Message`, `QuestionCard`, `SessionRow`, `SessionStatusLabel`, `StageIndicator`, `Timeline`) |
| Blocks | `Blocks/Session`: `SessionList`, `SessionDetail`, `ApprovalInbox` の空の一覧、失敗、読み取り専用、モバイルの状態 |
| Screens | `Sessions panel` |

ブロックの story はダミーの API レスポンスで描画する。サーバーなしで状態を切り替えて確認できる。toolbar で言語(`ko`, `ja`, `en`)とテーマ(ライト、ダーク)を切り替える。

## ローカルで立ち上げる

コンポーネントを修正しながら確認するには、リポジトリのルートで立ち上げる。

```sh
bun run --cwd apps/storybook dev
```

`http://127.0.0.1:6006` で開く。
