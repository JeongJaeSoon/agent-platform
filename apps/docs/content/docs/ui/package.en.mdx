This page shows how to use `@werft-ai/ui` in a React app outside this repository. You build the package in the repository, pack it into a tarball, and `npm install` that file in the app. The app does not need Tailwind.

<Callout type="warn">
The package is not published to a registry yet, so for now the tarball below is the only way to install it. `@werft-ai/react` (the hooks and session blocks) is not distributed, so apps outside the repository cannot use it.
</Callout>

<Callout type="info">
This repository is source-available. The package carries the repository's `LICENSE`, and it may not be used or distributed without the copyright holder's written permission.
</Callout>

## Make the tarball

Run these at the repository root. You need the Bun the repository pins, 1.3.14 (`packageManager` in the root `package.json`), and npm.

```sh
bun install
bun run --cwd packages/ui build:package
npm pack ./packages/ui/dist
```

`build:package` writes the built JavaScript and type declarations, the CSS, a `package.json` for distribution, and `LICENSE` into `packages/ui/dist`. `npm pack` packs that directory into `werft-ai-ui-<version>.tgz` in the current directory. The version is the `version` in `packages/ui/package.json`.

## Install it in an app

The example is a Vite + React + TypeScript app. If you do not have one, create it with `npm create vite@latest my-app -- --template react-ts`.

`@werft-ai/ui` takes `react` and `react-dom` `^19.3.0` as peer dependencies. If the app's React is older, upgrade it first, then install the tarball you made.

```sh
npm install react@^19.3.0 react-dom@^19.3.0
npm install <path to the repository>/werft-ai-ui-0.0.0.tgz
```

Radix, `class-variance-authority`, `clsx`, `tailwind-merge`, and `lucide-react` are dependencies of the package and are installed with it.

## Import the CSS

Import the prebuilt `styles.css` once. It holds the tokens, the rules for the kit's elements, and the utility classes the kit uses, so the components render without Tailwind.

```tsx title="src/main.tsx"
import "@werft-ai/ui/styles.css";
import { Button, Card } from "@werft-ai/ui";
```

`styles.css` does not include Tailwind's preflight (its global reset). It sets one global rule: every element's default `border-color` is `--ap-color-border`, so an element the app gives only `border: 1px solid`, with no colour, draws in that colour. The resets the kit expects (borders, margins, button backgrounds, link underlines, and so on) apply only to the kit's elements and what is inside them, at zero specificity. App markup you put inside a kit component also loses the browser's default margins and underlines. The kit's rules sit in a cascade layer, so the app's CSS outside any layer always wins.

### Tailwind v4 apps

To use the kit's utility names (`bg-primary`, `text-control`, `rounded-control`, and others) in the app's own markup, import `theme.css` after `styles.css` in the app's CSS. `theme.css` connects the tokens to Tailwind utilities.

```css title="src/index.css"
@import "tailwindcss";
@import "@werft-ai/ui/styles.css";
@import "@werft-ai/ui/theme.css";
```

The classes the kit's components use are already in `styles.css`, so you do not need to scan `node_modules` with `@source`.

## Fonts

The package ships no fonts. `--ap-font-sans` (Geist, then Pretendard Variable) and `--ap-font-mono` (Geist Mono first) pick the typeface, and if the app does not load those fonts, text falls back to the system fonts at the end of each list. To show Hangul in Pretendard, the app loads it itself. This repository's web console uses the dynamic subset from the `pretendard` package.

```sh
npm install pretendard
```

```tsx title="src/main.tsx"
import "pretendard/dist/web/variable/pretendardvariable-dynamic-subset.css";
```

## Theme

Light is the default. Turning on the dark theme works the same as in [Apply the theme](/ui/theme).

## Import paths

| Path | Contents |
| --- | --- |
| `@werft-ai/ui` | The two layers below and all of foundations (`cn` and others) |
| `@werft-ai/ui/primitives` | `Button`, `Card`, `Dialog`, `Tabs`, `Input`, `Skeleton`, and others |
| `@werft-ai/ui/patterns` | `ConfirmDialog`, `EmptyState`, `ErrorState`, `PageHeader`, `Stepper`, and others |
| `@werft-ai/ui/styles.css` | The prebuilt CSS. Usually the only one you import |
| `@werft-ai/ui/theme.css` | The token connection for Tailwind v4 apps |
| `@werft-ai/ui/tokens.css` | Only the `--ap-*` variables |
