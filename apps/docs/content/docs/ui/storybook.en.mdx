The API (props) and the states of individual components are in Storybook. It is hosted in the same place as this docs site.

- <SiblingLink href="/storybook/">Open Storybook</SiblingLink>

## What it contains

| Group | Components |
| --- | --- |
| Primitives | `Badge`, `Button`, `Card`, `Checkbox`, `Dialog`, `DropdownMenu`, `Field`, `Input`, `NativeSelect`, `Popover`, `RadioGroup`, `Stepper`, `Tabs`, `Textarea` |
| States | `EmptyState`, `ErrorState`, `Skeleton` |
| Patterns | `ConfirmDialog`, `DestructiveActionDialog`, `Receipt`, `StatusLabel`, session pieces (`ApprovalCard`, `Composer`, `Message`, `QuestionCard`, `SessionRow`, `SessionStatusLabel`, `StageIndicator`, `Timeline`) |
| Blocks | `Blocks/Session`: the empty list, failure, read-only, and mobile states of `SessionList`, `SessionDetail`, and `ApprovalInbox` |
| Screens | `Sessions panel` |

The block stories render with fake API responses. You can change states without a server. Use the toolbar to switch the language (`ko`, `ja`, `en`) and the theme (light, dark).

## Run it locally

To view components while editing them, start it from the repository root.

```sh
bun run --cwd apps/storybook dev
```

It opens at `http://127.0.0.1:6006`.
