---
title: "receipt"
description: 명령 하나가 어떻게 끝났는지 남는 기록을 읽는다
---

메시지, 제어(interrupt·pause·resume·close·terminate·복구 결정·프로필 변경), push 요청과 결정, 계정·key 관리 같은 명령은 receipt를 남긴다. receipt는 누가(`actor`), 무엇을(`operation`, `target_ref`) 했고 어떻게 끝났는지(`status`, `result`, `error`)를 담는다. 비동기 명령은 응답의 `receipt_status`가 `accepted`이고, 끝났는지는 receipt를 다시 읽어 본다. scope는 `sessions:read`다.

| `status` | 뜻 |
| --- | --- |
| `accepted` | 받았고 아직 끝나지 않았다 |
| `succeeded` | 끝났다. 결과는 `result` |
| `failed` | 거절되거나 실패했다. 이유는 `error`와 `result.refusal` |
| `unknown` | 결과를 알 수 없다 |

## 읽기

응답의 `receipt_id`로 `GET /v1/receipts/{id}`를 부른다. [거부](/approvals/reject)에서 만든 요청의 receipt를 읽는다.

```bash
pr=$(curl -sS "$API/v1/sessions/$SID/push-requests/$PUSH_ID" -H "Authorization: Bearer $KEY")
for id in $(echo "$pr" | jq -r '.request_receipt_id, .decision_receipt_id'); do
  curl -sS "$API/v1/receipts/$id" -H "Authorization: Bearer $KEY" \
    | jq -c '{operation, status, actor: .actor.principal.kind, decision: .result.decision}'
done
```

```text
{"operation":"request_push","status":"succeeded","actor":"api_key","decision":null}
{"operation":"decide_push","status":"succeeded","actor":"api_key","decision":"reject"}
```

거절된 요청은 오류 본문의 `error.details.receipt_id`가 그 receipt를 가리킨다. 거절도 기록이 남는다는 뜻이다.

## 끝날 때까지 기다리기

비동기 제어의 receipt는 `accepted`에서 `succeeded`나 `failed`로 바뀐다. 기다리는 동안 다른 결과가 나와도 멈추도록 둘 다 본다.

```bash
REV=$(curl -sS "$API/v1/sessions/$SID" -H "Authorization: Bearer $KEY" | jq .revision)
RID=$(curl -sS "$API/v1/sessions/$SID/pause" \
  -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "$(jq -nc --argjson r "$REV" '{expected_revision: $r, reason: "lunch"}')" | jq -r .receipt_id)
until curl -sS "$API/v1/receipts/$RID" -H "Authorization: Bearer $KEY" \
  | jq -e '.status | IN("succeeded", "failed", "unknown")' >/dev/null; do
  sleep 2
done
curl -sS "$API/v1/receipts/$RID" -H "Authorization: Bearer $KEY" \
  | jq '{operation, status, state: .result.resulting_admission_state}'
```

```text
{
  "operation": "pause",
  "status": "succeeded",
  "state": "paused"
}
```

receipt에는 비밀 값이 들어가지 않는다. 남의 범위에 있는 receipt는 404다.
