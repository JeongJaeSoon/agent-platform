# 콘솔·Slack 용어집

한국어를 원문으로 한다. 같은 기능은 화면 제목, 버튼, 안내, 접근성 이름과 Slack 알림에서 같은 용어를 쓴다. 사용자 입력·식별자·API 필드·오류 코드는 번역하지 않는다.

## 문체

- 일본어 안내 문장은 `です・ます`로 쓰고, 지시는 `〜してください`로 쓴다. 버튼·제목·상태는 짧은 명사나 동작형으로 쓴다. `ください`와 `お願いします`를 같은 종류의 안내에서 임의로 섞지 않는다.
- 영어 제목·버튼·상태는 sentence case를 쓴다. 문장 첫 단어, 고유명사와 API·ID·MCP 등의 약어만 대문자로 쓴다. 화면 이름을 안내에서 인용할 때는 실제 표시 이름과 일치시킨다.
- 관리자(Admin)와 소유자(Owner)를 구분한다. 에이전트 담당자를 Owner로 번역하지 않는다.
- 생성 마법사의 활성화 단계는 쉬운 동작 표현인 `켜기 / 有効化 / Turn on`을 쓴다. 릴리스 관리 화면의 `활성화 / 有効化 / Activate`와 같은 동작이며, 마법사를 안내하는 문서에서는 실제 단계 이름을 인용한다.
- Queued와 Idle은 서로 다른 상태다. 둘을 모두 일본어 `待機中`으로 표시하지 않는다. 세션 상태와 실행 상태도 합치지 않는다.
- 에이전트 맵의 실행 상태는 별도 축이다. `wait`는 사람의 답변을 기다리는 `답변 대기 / 回答待ち / Waiting for an answer`, `idle`은 활성 실행이 없는 `실행 대기 / 実行待ち / Idle`이다. 실행 `idle`에는 작업자 배정 전 상태도 포함되므로 세션의 `入力待ち`와 같게 표시하지 않는다.
- 보간 변수(`{release}`, `{turn}`, `{name}` 등), API 필드(`active_release_id` 등), 권한 모드(`auto`, `bypassPermissions` 등)는 철자와 개수를 그대로 유지한다.
- Slack의 화면·필드 이름(`Request URL`, `App Manifest`, `Refresh Token` 등)은 사용자가 실제 설정 화면에서 찾을 수 있도록 원래 표기를 유지한다.
- 제품 이름은 이 검수에서 변경하지 않는다. 내부 모듈 이름을 사용자 안내에 추가하지 않는다.
