# エージェントを Slack に接続する

エージェント詳細の **Slack** タブでアプリの状態を確認する。新規作成では名前・仕事内容・リリース・有効化の後に **チャンネル接続** が表示され、同じ部品を使用する。接続は後からでもよい。

アプリをインストールすると、Slack タブは 1 ページになる。上部の状態行に接続状態・ボット ID・ホームチャンネル・DM を受け取るかどうかが並び、その下に **チャンネル**、**基本**、**詳細**、**危険な操作** が続く。左のセクション一覧で選ぶとそのセクションへ移動する。狭い画面では一覧が本文の上のボタン 1 つに折りたたまれ、ボタンに現在のセクション名が表示される。開いてセクションを選ぶと一覧はまた折りたたまれる。

1. エージェントを有効にし、**Slack アプリを作成してインストール**を選ぶ。ワークスペース管理者によるアプリ作成設定が必要となる。
2. Slack の同意画面でインストールする。コールバックが処理を終えると Slack タブに戻り、画面下部に結果の通知が出る。同意の拒否や期限切れの場合は失敗の通知が出るので、新しいインストールを開始する。使用済みリンクは自動再送しない。権限やイベント設定が変わったら、**詳細**のアプリカードで**再インストール**を選ぶ。同じカードのアプリ ID の行では、**コピー**でアプリ ID をコピーし、**Slack で開く**で Slack のアプリ設定ページを新しいタブで開く。
3. インストール後にホームチャンネルがなければ、Slack タブは **ホームチャンネルの設定** の手順だけを表示する(**詳細**・**危険な操作**はそのまま)。**ホームチャンネルを選ぶ**でチャンネルを選ぶと、そのチャンネルが使用中かつホームとして保存され、ほかのセクションが表示される。非公開チャンネルには一覧に `/invite` の案内が付く。
4. **チャンネル** セクションの **チャンネルを追加**で名前の先頭から検索し、**接続**を選ぶ。結果は画面下部の通知で出る。接続したチャンネルごとに **このチャンネルで使用** と **メンション時のみ応答** のスイッチがある。使用をオフにするとそのチャンネルでは応答せず、メンション時のみ応答をオフにするとメンションなしでチャンネルに書かれた投稿にも応答する。追加したチャンネルやエージェントを招待したチャンネルは使用オンで接続される。**基本**の **新しいチャンネルの既定の応答** スイッチは新しいチャンネルがメンション時のみ応答するかを決め、切り替えるとすぐサーバーに保存される。接続済みのチャンネルは変わらない。初期値はオン(メンション時のみ)である。**DM を受け取る**は DM の接続設定を別に保存する。
5. オフにしたチャンネルを使用に戻すと、メンション時のみ応答する状態に戻る。保存に失敗するとエラーを表示し、保存済み設定を維持する。**ホームに設定**でホームチャンネルを変更する。

公開チャンネルは応答をオンにして接続するか、後で応答をオンにするとサーバーがボットを参加させる。応答がオフのチャンネルには参加しない。非公開チャンネルにはボットが自分で参加できないため、`/invite` で招待する。ボットがまだいない非公開チャンネルには **/invite が必要** タグとコピーボタンが付き、押すと `/invite @<エージェントの slug>` をクリップボードにコピーする。ブラウザーがクリップボードを拒否した場合は、コマンドを選択した欄が出るので手動でコピーする。検索には公開チャンネルと参加済みの非公開チャンネルが含まれる。**もっと見る**で次のページを取得する。Slack の制限による古い結果や一覧の上限は画面で案内する。

**危険な操作**の **Slack の接続を解除** の行で **接続解除** を選ぶと、エージェントの Slack ID とチャンネル接続を失効させる。Slack アプリは残り、再インストールできる。**Slack アプリを削除** の行の **アプリを削除** は Slack アプリと保存済み認証情報を削除する。元に戻せず、もう一度接続すると新しいアプリが作られる。どちらも影響を説明する確認画面を表示する。

セクション一覧のリンクで Enter を押すとそのセクションにフォーカスが移る。スイッチへの移動は Tab、切り替えは Space を使う。結果とエラーは支援技術にも通知する。

イベント登録が終わらない場合、コールバックに確認が必要な旨を表示する。現在の参照 API にはイベント登録状態・確認時刻・公開イベント URL がないため、再訪問時に推測して表示しない。実際の Slack メンションと接続解除後のイベント処理は別途人による確認が必要となる。
