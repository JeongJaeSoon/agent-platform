# エージェントを Slack に接続する

エージェント詳細の **Slack** タブでアプリの状態を確認する。新規作成では名前・仕事内容・リリース・有効化の後に **チャンネル接続** が表示され、同じ部品を使用する。接続は後からでもよい。

1. エージェントを有効にし、**Slack アプリを作成してインストール**を選ぶ。ワークスペース管理者によるアプリ作成設定が必要となる。
2. Slack の同意画面でインストールする。コールバックが処理を終えると Slack タブに戻る。同意の拒否や期限切れの場合は新しいインストールを開始する。使用済みリンクは自動再送しない。
3. **チャンネル**で名前の先頭から検索し、**接続**を選ぶ。新規チャンネルの応答スイッチは現在の画面から追加するチャンネルだけに適用する。
4. 接続済みチャンネルのスイッチをオンにするとメンションに応答し、オフにすると応答しない。保存に失敗するとエラーを表示し、保存済み設定を維持する。**ホームに設定**でホームチャンネルを変更する。

公開チャンネルにはサーバーが自動参加する。非公開チャンネルには `/invite` でボットを招待する。検索には公開チャンネルと参加済みの非公開チャンネルが含まれる。**もっと見る**で次のページを取得する。Slack の制限による古い結果や一覧の上限は画面で案内する。

**接続解除**はエージェントの Slack ID とチャンネル接続を失効させる。**アプリを削除**は Slack アプリと保存済み認証情報を削除する。どちらも影響を説明する確認画面を表示する。

タブでは矢印キー、スイッチへの移動は Tab、切り替えは Space を使う。結果とエラーは支援技術にも通知する。

イベント登録が終わらない場合、コールバックに確認が必要な旨を表示する。現在の参照 API にはイベント登録状態・確認時刻・公開イベント URL がないため、再訪問時に推測して表示しない。実際の Slack メンションと接続解除後のイベント処理は別途人による確認が必要となる。
