# エージェントを Slack に接続する

エージェント詳細の **Slack** タブでアプリの状態を確認する。新規作成では名前・仕事内容・リリース・有効化の後に **チャンネル接続** が表示され、同じ部品を使用する。接続は後からでもよい。

アプリをインストールすると、Slack タブは 1 ページになる。上部の状態行に接続状態・ボット ID・ホームチャンネル・ダイレクトメッセージが並び、その下に **チャンネル**、**基本**、**詳細**、**危険な操作** が続く。左のセクション一覧で選ぶとそのセクションへ移動する。狭い画面では一覧が本文の上に置かれる。

1. エージェントを有効にし、**Slack アプリを作成してインストール**を選ぶ。ワークスペース管理者によるアプリ作成設定が必要となる。
2. Slack の同意画面でインストールする。コールバックが処理を終えると Slack タブに戻り、画面下部に結果の通知が出る。同意の拒否や期限切れの場合は失敗の通知が出るので、新しいインストールを開始する。使用済みリンクは自動再送しない。権限やイベント設定が変わったら、**詳細**のアプリカードで**再インストール**を選ぶ。
3. **チャンネル** セクションの **チャンネルを追加**で名前の先頭から検索し、**接続**を選ぶ。結果は画面下部の通知で出る。**基本**の新規チャンネル応答スイッチは現在の画面から追加するチャンネルだけに適用する。**ダイレクトメッセージ**は DM の接続設定を別に保存する。
4. 接続済みチャンネルのスイッチをオンにするとメンションに応答し、オフにすると応答しない。保存に失敗するとエラーを表示し、保存済み設定を維持する。**ホームに設定**でホームチャンネルを変更する。

公開・非公開の両方で `/invite` によりボットを招待する。現在のサーバーは接続の保存だけではチャンネルに参加しない。ボットのいないチャンネルには **/invite が必要** タグとコピーボタンが付き、押すと `/invite @<エージェントの slug>` をクリップボードにコピーする。ブラウザーがクリップボードを拒否した場合は、コマンドを選択した欄が出るので手動でコピーする。検索には公開チャンネルと参加済みの非公開チャンネルが含まれる。**もっと見る**で次のページを取得する。Slack の制限による古い結果や一覧の上限は画面で案内する。

**接続解除**はエージェントの Slack ID とチャンネル接続を失効させる。**アプリを削除**は Slack アプリと保存済み認証情報を削除する。どちらも影響を説明する確認画面を表示する。

セクション一覧のリンクで Enter を押すとそのセクションにフォーカスが移る。スイッチへの移動は Tab、切り替えは Space を使う。結果とエラーは支援技術にも通知する。

イベント登録が終わらない場合、コールバックに確認が必要な旨を表示する。現在の参照 API にはイベント登録状態・確認時刻・公開イベント URL がないため、再訪問時に推測して表示しない。実際の Slack メンションと接続解除後のイベント処理は別途人による確認が必要となる。
